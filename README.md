# 神明不会下棋 (God Don't Know How To Play Chess)

一款以中国象棋规则为基底、规则本身可以被"神明"随局改写的像素风战棋 RPG。

## 简介

少年在村口看老人下棋,旁边一个小孩看不懂棋。少年好心教他,小孩连输几局后开始耍赖——先是偷偷挪子,然后凭空变出"骑士""魔法师"这类棋子,接着棋盘开始变形、隆起高山、裂开河流……最后一怒之下把少年扔进自己创造的异世界。少年这才发现:这个小孩是神,而他其实根本不会下棋——他只是不能输。

## 模式

- **剧情模式**:章节式冒险,每章引入新机制(幻想棋子、地形、神谕规则修改、动态胜负条件)
- **战役模式**:加载地图包 + 棋子包,完成单局对弈

## 技术要点

- 引擎:Godot 4.x
- 一切对局内容 = 数据包(棋子/地图/规则/胜负条件),引擎只做执行器
- RuleOp 管线:运行时规则修改(造子/改棋盘/临时规则/换胜负条件)
- 逻辑与表现分离,引擎支持无头模式跑 AI 自对弈回归测试
